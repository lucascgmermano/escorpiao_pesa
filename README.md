## Painel de Estratificação de Risco Assistencial para o Escorpionismo

O PESA é um projeto de análise de dados voltado ao reconhecimento do cenário epidemiológico do escorpionismo no estado de São Paulo. Sua proposta é integrar informações disponíveis em bases públicas para produzir indicadores territorializados que ajudem a identificar populações, municípios ou áreas com maior necessidade de atenção e planejamento.
