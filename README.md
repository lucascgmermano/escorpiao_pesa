## PESA — Painel de Estratificação de Risco Assistencial

O PESA é um projeto de análise de dados voltado ao reconhecimento de situações de risco assistencial e ao apoio à gestão em saúde. Sua proposta é integrar informações disponíveis em bases públicas para produzir indicadores territorializados que ajudem a identificar populações, municípios ou áreas com maior necessidade de atenção e planejamento.
